# 📌 DeepThought Assignment

This project is a **data processing pipeline** built as part of the DeepThought assignment. It processes company data from a CSV file and applies transformations to generate structured results.

---

## 🚀 Overview

- Reads data from `companies.csv`
- Cleans and processes the dataset
- Applies transformation logic using Python
- Documents approach and design decisions
